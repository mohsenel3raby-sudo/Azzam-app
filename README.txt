AZZAM Android

This project wraps https://azzam-stor.web.app/ in an Android WebView.

Build in Android Studio:
1. Open the AZZAM-Android folder.
2. Let Gradle sync.
3. Build > Build APK(s).
4. APK path: app/build/outputs/apk/debug/app-debug.apk

Package: com.azzam.store
Minimum Android: 6.0 (API 23)
Target SDK: 35
